# Football Team Cards

## About the Project

Football Team Cards is a web application that displays football team information and player cards. Users can view team statistics, identify the team captain, and filter players by their positions using a dropdown menu.

This project was built as part of my JavaScript learning journey to practise DOM manipulation, arrays, objects, functions, and event handling.

## Features

- Display team name, year, and head coach.
- Show players in individual cards.
- Identify the team captain.
- Filter players by position:
  - Forward
  - Midfielder
  - Defender
  - Goalkeeper
- Display all players using the "All Players" option.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the application in your browser.
2. View the team statistics and player cards.
3. Use the dropdown menu to select a player position.
4. View only the players matching the selected position.
5. Select "All Players" to display the complete team again.

## JavaScript Concepts Practised

- Objects and arrays
- Object properties and boolean values
- DOM selection using `document.getElementById()`
- Creating HTML elements using `document.createElement()`
- Updating content with `textContent`
- Adding CSS classes with `classList.add()`
- Handling dropdown changes with `addEventListener()`
- Filtering arrays using `filter()`
- Displaying dynamic content using `forEach()`

## Project Goal

The goal of this project was to improve my understanding of JavaScript by creating dynamic player cards and implementing interactive filtering functionality.
